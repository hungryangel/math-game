# 도형 이동 대탐험 🔄

**▶ 바로 해보기: https://hungryangel.github.io/math-game/**

초등학교 4학년 **평면도형의 이동(밀기 · 뒤집기 · 돌리기)** 단원을 게임으로 익히는 학습 웹앱입니다.
빌드 도구 없이 동작하는 순수 HTML/CSS/JS이며, 정적 호스팅에 그대로 올리면 됩니다.

## 실행

```bash
python3 -m http.server 8899
```

브라우저에서 `http://localhost:8899` 접속. (`index.html`을 더블클릭해 파일로 바로 열어도 동작합니다.)

## GitHub Pages 배포

저장소에 그대로 올린 뒤 Settings → Pages → Source를 `main` 브랜치 루트로 지정하면 됩니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (5개 화면 컨테이너) |
| `styles.css` | 전체 스타일 |
| `js/shapes.js` | 도형 데이터 + 변환 로직(밀기/뒤집기/돌리기) |
| `js/stages.js` | 챕터·스테이지 구성 + 문제 생성기 |
| `js/fx.js` | 효과음(WebAudio 합성) + 색종이 효과 |
| `js/app.js` | 화면 렌더링 & 게임 진행 |

## 학습 설계

- **배우기 놀이터** — 버튼을 누르면 도형이 실제로 뒤집히고 돌아가는 애니메이션을 보여 줍니다.
  뒤집기에는 거울축(점선), 돌리기에는 회전 중심(점)을 함께 표시해 "무엇을 기준으로 움직이는가"를 눈으로 익힙니다.
  **밀기** 버튼도 있어서 "밀기는 위치만 바뀌고 모양은 그대로"라는 교과서 핵심을 직접 확인할 수 있습니다.
- **3챕터 15스테이지** — 뒤집기 → 돌리기 → 종합 순으로 잠금 해제되며, 정답률에 따라 별 1~3개를 받습니다.
- **문제 유형 3가지**
  - `결과 맞히기` — 지정한 동작을 한 결과를 4지선다로 고르기
  - `동작 찾기` — 처음/결과 도형을 보고 어떤 동작이었는지 고르기
  - `직접 조작` — 버튼을 눌러 목표 모양을 직접 만들기 (최소 횟수 달성 시 "완벽!")
- **오답 해설** — 틀리면 원래 도형이 **실제로 움직이는 애니메이션**을 보여 주고, 그 동작의 설명을 함께 띄웁니다.

## 설계상 중요한 제약

문제로 쓰는 도형은 **8가지 변환(항등·좌우·상하·90°·180°·270°·대각선 2종) 결과가 모두 서로 달라야** 합니다.
대칭인 도형은 "좌우 뒤집기"와 "180° 돌리기" 결과가 같아져 정답이 두 개가 되기 때문입니다.
`js/shapes.js`의 `isFullyAsymmetric()`이 이를 자동 검사하며, 통과하지 못한 도형은 콘솔 경고와 함께 제외됩니다.
도형을 추가할 때는 이 검사를 반드시 통과시켜야 합니다.

진행 상황은 `localStorage`(`mg_progress_v1`)에 저장됩니다.
